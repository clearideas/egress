# Third-party software

The npm package has no runtime dependencies and does not bundle Squid. The optional Dockerfile installs Squid and Alpine packages into a separate container image. Squid is GPL-2.0-or-later; image distributors must inventory the exact built image, retain its component notices and provide any corresponding source required by those components' licenses. The MIT license in this repository applies to the original Clear Ideas code and documentation, not to those installed packages.
